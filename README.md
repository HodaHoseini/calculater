# Simple Python Calculator

A simple command-line calculator written in Python.

## Features

The calculator can perform four basic mathematical operations:

* Addition
* Subtraction
* Multiplication
* Division

## Technologies

* Python

## Python Concepts Practiced

* Functions
* User input
* Conditional logic
* Dictionaries
* Basic mathematical operations

## How to Run

Make sure Python is installed on your computer.

Run the program with:

```bash
python calculator.py
```

Then enter two numbers and choose the mathematical operation you want to perform.

## Purpose

This project was created to practice Python fundamentals and build a simple interactive command-line application.
